# Every Square Has a Name — narration script

Files, ranks and square names (coordinates) for K-1 chess kids. The full narration with timecodes, for recording your own voice or reading it live.

**Running time:** 6:39  
**Color code on screen:** letters / files are **blue**, numbers / ranks are **orange**.  
**Saying square names:** letter first, then number — a1 = "ay one", e4 = "ee four", f3 = "eff three".  
**Timecodes** show when each line starts (minutes:seconds.tenths). ⏸ = built-in thinking time while students answer out loud.
